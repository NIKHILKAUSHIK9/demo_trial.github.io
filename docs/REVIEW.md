# StarNest UI review: bugs found, fixes, how to run

Run (real PARSEC + IRSA): `pip install -r requirements.txt && uvicorn main:app --port 8000`, then open
`http://127.0.0.1:8000/` (serves index.html) or the HTML file directly. No backend = in-browser engine (a badge says so).

## Not fixed (needs your decision)
- Classification thresholds (WD / giant / PMS) are uncalibrated heuristics. The BC_G polynomial gives -0.31 mag at solar colour (BC_G,sun is about +0.07).
- Defaults (341 pc, E(B-V) 0.15, age 7.5, DM 7.66) are single-cluster values; 0.15 is high for a 341 pc line of sight.
- Backend keeps one session in memory (local use); add per-session ids before hosting publicly.
- Unverified here: real IRSA/PARSEC replies (hosts blocked in my sandbox) and styling (Tailwind CDN blocked).
